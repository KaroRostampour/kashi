صفحه‌ساز کدمحور و سبک: صفحه را کاشی‌به‌کاشی با کد خودتان بسازید.

== توضیحات ==

کاشی برای طراحانی ساخته شده که صفحه‌ها را با کد (یا با کمک هوش مصنوعی) می‌سازند.
هر بخش صفحه یک «کاشی» است با HTML، CSS و JS خودش؛ کاشی‌ها کنار هم صفحه را می‌سازند.

* ویرایشگر زنده تمام‌صفحه با پیش‌نمایش داخل قالب واقعی سایت
* چسباندن کد کامل؛ CSS هر کاشی فقط روی خودش اثر دارد
* طرح‌بندی تمام‌عرض / بوم خالی / پیش‌فرض قالب
* کتابخانه کاشی (کپی یا لینک‌شده) و تاریخچه نسخه‌ها
* سئو: همگام‌سازی محتوا با Rank Math / Yoast، CSS و اسکیما در head، تصاویر lazy، بررسی‌کننده سئوی زنده
* بدون CSS/JS سراسری؛ فقط کد خودتان و فقط در صفحه‌ای که لازم است
* هدر و فوتر سایت با کاشی (با هر قالبی، با شرط نمایش)
* ویرایش مستقیم متن، لینک و تصویر داخل پیش‌نمایش، بدون دست زدن به کد
* آپدیت خودکار از سرور خودتان، با بررسی امضای SHA-256

== نصب ==

1. اگر نسخه قبلی (Lite Sections) نصب است، اول آن را غیرفعال و حذف کنید. داده‌ها و صفحه‌ها حفظ می‌شوند.
2. فایل zip را از «افزونه‌ها ← افزودن ← بارگذاری» نصب و فعال کنید.
3. در لیست برگه‌ها روی «ویرایش با کاشی» بزنید.

== آپدیت خودکار ==

۱. روی یک سایت اصلی (مثلاً سایت شخصی خودتان): کاشی ← تنظیمات ← «سرور آپدیت» را فعال کنید.
۲. فایل zip نسخه جدید را از رسانه انتخاب و ذخیره کنید؛ نسخه و امضا خودکار خوانده می‌شود.
۳. آدرسی که نمایش داده می‌شود را در «آدرس سرور آپدیت» بقیه سایت‌ها وارد کنید.
از این به بعد هر نسخه جدید، در همه سایت‌ها دکمه «به‌روزرسانی» می‌آورد.

== هدر و فوتر ==

یک کاشی بسازید، «محل نمایش» را «هدر سایت» یا «فوتر سایت» کنید و ذخیره کنید.
کاشی جای المان <header>/<footer> قالب را می‌گیرد. اگر قالب این تگ‌ها را ندارد، در «المان قالب»
شناسه یا کلاس آن را بنویسید (مثل #masthead).

== شورت‌کد ==

[kashi id="12"] — نمایش یک کاشی از کتابخانه (شورت‌کد قدیمی [lsec] هم کار می‌کند).

== PHP اختصاصی ==

کد PHP از داخل ویرایشگر اجرا نمی‌شود (امنیت). شورت‌کد خود را در Code Snippets
یا در پوشه wp-content/kashi-php تعریف کنید و در کاشی‌ها استفاده کنید.
