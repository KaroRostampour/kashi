صفحه‌ساز کدمحور و سبک: صفحه را کاشی‌به‌کاشی با کد خودتان بسازید.

== توضیحات ==

کاشی برای طراحانی ساخته شده که صفحه‌ها را با کد (یا با کمک هوش مصنوعی) می‌سازند.
هر بخش صفحه یک «کاشی» است با HTML، CSS و JS خودش؛ کاشی‌ها کنار هم صفحه را می‌سازند.

* ویرایشگر زنده تمام‌صفحه با پیش‌نمایش داخل قالب واقعی سایت
* چسباندن کد کامل؛ CSS هر کاشی فقط روی خودش اثر دارد
* طرح‌بندی تمام‌عرض / بوم خالی / پیش‌فرض قالب
* کتابخانه کاشی (کپی یا لینک‌شده) و تاریخچه نسخه‌ها
* سئو: همگام‌سازی محتوا با Rank Math / Yoast، CSS و اسکیما در head، تصاویر lazy، بررسی‌کننده سئوی زنده
* بدون CSS/JS سراسری؛ فقط کد خودتان و فقط در صفحه‌ای که لازم است
* هدر و فوتر سایت با کاشی (با هر قالبی، با شرط نمایش)
* ویرایش مستقیم متن، لینک و تصویر داخل پیش‌نمایش، بدون دست زدن به کد
* آپدیت خودکار از سرور خودتان، با SHA-256 و امضای دیجیتال Ed25519
* انتقال کاشی‌ها، هدر/فوترها و صفحه‌ها بین سایت‌ها با یک فایل (خروجی / ورودی)
* حالت اینترنت ملی، آپدیت آفلاین امضاشده و فونت وزیرمتن محلی

== نصب ==

1. اگر نسخه قبلی (Lite Sections) نصب است، اول آن را غیرفعال و حذف کنید. داده‌ها و صفحه‌ها حفظ می‌شوند.
2. فایل zip را از «افزونه‌ها ← افزودن ← بارگذاری» نصب و فعال کنید.
3. در لیست برگه‌ها روی «ویرایش با کاشی» بزنید.

== آپدیت خودکار (گیت‌هاب) ==

نسخه‌های جدید از Release های مخزن گیت‌هاب KaroRostampour/kashi خوانده می‌شوند.
۱. کاشی ← تنظیمات ← منبع آپدیت: «گیت‌هاب».
۲. چون مخزن خصوصی است، یک توکن بسازید: گیت‌هاب ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token؛ Repository access: فقط kashi؛ Permissions ← Contents: Read-only. توکن را در «توکن گیت‌هاب» بچسبانید و ذخیره کنید.
   (یا در wp-config.php: define( 'KASHI_GITHUB_TOKEN', '...' );)
۳. انتشار نسخه جدید: کافی است کد با شماره نسخه بالاتر در شاخه main گیت‌هاب ثبت شود؛ سایت‌ها خودشان آن را می‌بینند.
   (اختیاری: اگر Release با تگ مثل v1.4.1 و فایل kashi-1.4.1.zip بسازید، Release اولویت دارد.)
از آن به بعد همه سایت‌ها در «افزونه‌ها» دکمه «به‌روزرسانی» می‌بینند. فایل قبل از نصب با SHA-256 گیت‌هاب و شماره نسخه داخل zip بررسی می‌شود.

روش قدیمی (سرور آپدیت روی سایت خودتان با امضای Ed25519) همچنان در «پیشرفته» موجود است.

== اینترنت ملی ==

کاشی ← تنظیمات ← «اینترنت ملی و سرعت»:
* حالت اینترنت ملی: درخواست‌های سرور به wordpress.org، گراواتار، گوگل و سرورهای لایسنس فوراً رد می‌شوند تا پیشخوان معطل نشود. دامنه‌های .ir و خود سایت مسدود نمی‌شوند. بعد از وصل شدن اینترنت خاموشش کنید.
* فونت وزیرمتن محلی: در CSS کاشی‌ها font-family: Vazirmatn بنویسید؛ بدون گوگل‌فونت.
* آپدیت آفلاین: فایل zip و امضای آن را (از سرور آپدیت سایت اصلی) بارگذاری کنید.

== خروجی / ورودی ==

منوی کاشی ← «خروجی / ورودی». موارد را انتخاب و فایل را دانلود کنید؛ در سایت دیگر همان فایل را وارد کنید.
همه چیز جدید ساخته می‌شود (چیزی جایگزین نمی‌شود)، صفحه‌ها و هدر/فوترها پیش‌نویس می‌آیند، و ارجاع‌های [kashi id] خودکار درست می‌شوند.

== هدر و فوتر ==

منوی کاشی ← «هدر و فوتر» ← «ساخت هدر» یا «ساخت فوتر». کد را بچسبانید و ذخیره کنید.
(یا در ویرایشگر هر کاشی: دکمه «محل نمایش» ← هدر سایت / فوتر سایت.)
کاشی جای المان <header>/<footer> قالب را می‌گیرد. اگر قالب این تگ‌ها را ندارد، در «المان قالب»
شناسه یا کلاس آن را بنویسید (مثل #masthead).

== شورت‌کد ==

[kashi id="12"] — نمایش یک کاشی از کتابخانه (شورت‌کد قدیمی [lsec] هم کار می‌کند).

== PHP اختصاصی ==

کد PHP از داخل ویرایشگر اجرا نمی‌شود (امنیت). شورت‌کد خود را در Code Snippets
یا در پوشه wp-content/kashi-php تعریف کنید و در کاشی‌ها استفاده کنید.
کاشی خودش در این پوشه فایل محافظ (.htaccess و index.php) می‌سازد تا فایل‌ها از مرورگر اجرا نشوند
(Apache و LiteSpeed). روی سرور Nginx، یا برای اطمینان بیشتر، هر فایل را با این خط شروع کنید:
<?php defined( 'ABSPATH' ) || exit;
